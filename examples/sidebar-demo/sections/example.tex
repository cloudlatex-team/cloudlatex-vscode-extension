\section{A small LaTeX example}

LaTeX Workshop provides command completion while Cloud LaTeX builds the PDF.
For example, the sum of the first $n$ positive integers is
\begin{equation}
  \sum_{k=1}^{n} k = \frac{n(n+1)}{2}.
\end{equation}

\begin{center}
  \begin{tabular}{ll}
    Sidebar status & Meaning \\
    \hline
    Synced & The last synchronization completed \\
    Unsaved & Changes are still in the editor buffer \\
    Offline & Local changes await a connection \\
    Conflict & Both sides changed; choose a resolution \\
  \end{tabular}
\end{center}

After compilation, the PDF is downloaded to the workspace output folder.
The preview refreshes when the compiled PDF changes.
