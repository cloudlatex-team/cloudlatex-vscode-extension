\section{A project in your editor}

Register a Cloud LaTeX project by its URL, then choose an empty local folder.
The CL sidebar keeps the project, its files, and its synchronization status
together. The selected server address is carried over automatically.

\begin{enumerate}
  \item Open a registered project from the CL sidebar.
  \item Browse folders and open a source file.
  \item Save local edits to synchronize with Cloud LaTeX.
  \item Compile on Cloud LaTeX and preview the PDF with LaTeX Workshop.
\end{enumerate}

\section{Synchronization you can inspect}

Unsaved editor changes are marked separately from saved files.
While the editor is running, offline changes remain local. If both copies change, the existing
synchronization engine asks you to resolve the conflict before continuing.
